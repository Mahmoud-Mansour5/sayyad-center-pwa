# 📚 نظام إدارة مركز الأستاذ محمود الصياد للتطوير التعليمي (V3)

تطبيق ويب تقدمي (PWA) يعمل **أوفلاين بالكامل**، مخصص لإدارة الحضور والدرجات والملاحظات في المراكز التعليمية، مع مزامنة تلقائية للبيانات مع الخادم عند توفر الاتصال بالإنترنت.

---

## 🗂️ محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | الهيكل الأساسي للتطبيق (الواجهات، القوالب، النوافذ المنبثقة) |
| `styles.css` | التنسيقات الكاملة للتطبيق شاملة الوضع الليلي/النهاري (متجاوب، دعم RTL) |
| `app.js` | منطق التطبيق: المصادقة، المزامنة، العرض، الصلاحيات، وتصدير التقارير |
| `db.js` | طبقة التخزين المحلي (IndexedDB) مع نسخة احتياطية بـ localStorage |
| `sw.js` | Service Worker لتفعيل العمل أوفلاين والتخزين المؤقت (إصدار v1.2.0) |
| `manifest.json` | إعدادات تثبيت التطبيق كتطبيق PWA على الجوال/سطح المكتب |

## ✨ أهم الميزات (تحديثات الإصدار الشامل)

### 1. المظهر الليلي والنهاري (Dark / Light Mode) 🌓
- إمكانية التبديل بين الوضع الليلي (الافتراضي) والوضع النهاري عبر زر مخصص في الواجهة.
- يتم حفظ تفضيل المستخدم في `localStorage` ليتم تطبيقه تلقائيًا في الزيارات القادمة.

### 2. الدرجة العظمى المخصصة (Max Grades) 📝
- يمكن للسكرتارية الآن إدخال الدرجة العظمى بجانب درجة الطالب الفعلية في (الواجب والامتحان) لتقييم أدق.
- تظهر الدرجات في طابور اعتماد المدير بصيغة كسرية (مثال: واجب 15 / 20).

### 3. تصدير تقرير اليوم (Excel / CSV) 📊
- زر مخصص للمدير لتحميل سجلات اليوم المعتمدة بضغطة واحدة.
- يتم تصدير البيانات في ملف `CSV` مدعوم بترميز `UTF-8 BOM` لضمان قراءة اللغة العربية بشكل سليم في برنامج Excel.

### 4. إدارة حسابات السكرتارية (Add & Edit) ⚙️
- يمكن للمدير من خلال التطبيق إضافة حسابات سكرتارية جديدة (الاسم، الرقم السري، الدور).
- يمكنه أيضًا تحديد "المجموعات المسموحة" (RBAC) لكل سكرتير، بحيث لا يرى السكرتير سوى طلاب المجموعات المخصصة له فقط.
- جميع التعديلات تُحفظ محليًا وتُرسل تلقائيًا عبر محرك المزامنة للخادم.

### 5. نظام أكواد تسلسلي للطلاب 🔢
- عند إضافة طالب جديد (أوفلاين)، يقوم النظام بحساب أعلى كود موجود ويمنح الطالب الجديد الكود التالي مباشرة (يبدأ من 1000).
- تظهر رسالة فورية للسكرتارية بالكود الجديد لاستخدامه مباشرة قبل حتى أن تتم المزامنة مع الخادم.

### 6. نظام المراقبة وتتبع السجلات (Audit Trail) 🔍
- يتم تسجيل اسم السكرتير (`secretaryName`) الذي قام بتسجيل حضور أو درجات الطالب.
- يتم تسجيل اسم المدير (`approvedBy`) الذي قام بمراجعة واعتماد السجل.
- تُحفظ هذه البيانات في قاعدة البيانات وتُصدّر في تقارير الإكسيل لضمان الشفافية.

### 7. عدم الاعتماد على بيانات ثابتة (Dynamic Data)
- يتم سحب (الطلاب، الإعدادات، وحسابات السكرتارية) من خادم API (`Google Apps Script`) عند توفر الإنترنت.
- تعمل المنظومة بنسبة 100% دون إنترنت اعتمادًا على ذاكرة `IndexedDB`.

## 🔄 آلية المزامنة (Sync Engine)

يعمل `triggerSync()` تلقائيًا في الخلفية (عند استعادة الاتصال، أو كل 30 ثانية كمحاولة احتياطية)، ويقوم بإرسال البيانات المعلّقة بالترتيب:

1. **الطلاب الجدد** المضافين أوفلاين (`syncStatus: 'pending_creation'`)
2. **تحديثات السكرتارية** (حسابات جديدة أو تعديل صلاحيات) (`pendingSync: true`)
3. **سجلات الحضور والدرجات** (المعتمدة أو التي فشل إرسالها سابقًا)

---

## 🗄️ هيكلة قاعدة البيانات المحلية (IndexedDB)

| المخزن (Object Store) | المفتاح الأساسي | الوصف |
|---|---|---|
| `students` | `id` | قائمة الطلاب (شاملة الطلاب الجدد بحالة `pending_creation`) |
| `records` | `recordId` | سجلات الحضور/الدرجات/الملاحظات اليومية |
| `settings` | `key` | قوائم الإعدادات (`branches`, `years`, `days`, `times`, `groups`) |
| `secretaries` | `id` | حسابات تسجيل الدخول والصلاحيات |
| `meta` | `key` | بيانات تشغيلية عامة |

## 🚀 خطوات التشغيل والتجربة

1. تأكد من وضع الرابط الفعلي للـ API في ملف `app.js` عند المتغير `CONFIG.API_ENDPOINT`.
2. شغّل المجلد عبر أي خادم محلي (مثال: `npx serve .` أو `Live Server`) لتفعيل الـ Service Worker.
3. للتجربة أوفلاين في بيئة تطويرية، يمكنك الاستعانة بأدوات المطور (Console) لإضافة حساب أولي:

```javascript
db.upsertSecretary({
  id: 'master-1',
  name: 'المدير العام',
  pin: '9999',
  role: 'master'
});
